# 导游资格证押题卷刷题

2026 初级导游资格证押题卷（五）（六）（七）（八）的选择题刷题小程序，纯静态网页。

- 8 份卷子，每份 165 题（判断 40 / 单选 90 / 多选 35，满分 100）
- 逐题作答，交卷后统一出分数、对错一览和每题解析
- 进度保存在浏览器 localStorage
- 计分：判断、单选每题 0.5 分；多选每题 1 分，少选、多选、错选不得分

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

（`index.html` 通过 fetch 读取 `data.json`，需用 HTTP 服务打开，不能直接双击文件。）

## 文件

- `index.html`：小程序页面
- `data.json`：题库（题干、选项、答案、解析）
- `parse.py`：从答案卷 PDF 提取题库的脚本（需要 `pdftotext`，PDF 放在 `PDF_DIR` 目录，文件名见脚本）

## 说明

押题卷（六）科目三四第 137 题、押题卷（七）科目三四第 82 题在原答案卷中缺失，题目取自题目卷，答案与解析为补充内容。
